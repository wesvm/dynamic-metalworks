# Dynamic MetalWorks – Landing Page

Landing page corporativa desarrollada con **Astro** para *Dynamic MetalWorks*, empresa dedicada a servicios de metal mecánica con más de 20 años de experiencia.

## 🧱 Stack Tecnológico

- **Astro** – Framework web
- **Tailwind CSS** – Estilos
- **pnpm** – Gestor de paquetes
- **HTML / CSS / JavaScript**

## 📂 Estructura del Proyecto

```bash
./src
├── assets/              # Recursos estáticos (imágenes)
│   └── services/
├── components/          # Componentes reutilizables
│   └── icons/           # Íconos SVG / componentes de íconos
├── layouts/             # Layouts base
├── pages/               # Páginas (routing de Astro)
└── styles/              # Estilos globales
